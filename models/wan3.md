# Wan 3.0（通义万相）适配规范

依据阿里云百炼《万相3.0-视频生成》官方帮助文档整理。Wan 3.0 为闭源 API 模型，主打原生多镜头叙事与原生音频。

## 能力要点

- **原生最长 30 秒**多镜头叙事，单次生成自动产出同步台词、BGM 与音效——音频需求直接写进提示词，无需后期配音。
- **多镜头分镜格式**：每镜头 4–6 秒，用时间戳标注切点。
- **参考资产**：最多 10 张图、5 段视频、5 段音频、1 个网页链接或 1 个文档；提示词内以引用语法指定。
- **智能时长**：`duration = -1` 时模型自动推荐时长。
- 阿里云官方提供提示词优化 Skill（`wan3-pe.zip`）与本系统理念一致；本规范与之处可互相印证。

## 参数表

| 参数 | 合法值 | 建议 |
|---|---|---|
| resolution | 480P / 720P / 1080P（默认 1080P） | 草稿 480p，交付 1080p |
| ratio | 16:9 / 4:3 / 1:1 / 3:4 / 9:16 | 延长场景用 adaptive |
| duration | 2–30 秒，或 -1 智能时长 | 分镜时长和必须等于总时长 |
| frames / 音频开关 | 整数 / 布尔 | 按产品形态 |

## 提示词结构（长文本分镜）

单镜头直接一句；多镜头用时间戳分段，每段内写清：景别 + 主体动作 + 环境 + 运镜 + 光线，收尾可加整体风格总述。音频在对应镜头内写"台词："“环境音："“BGM:”。

```
[00:00 - 00:05] 全景：毛绒宇宙飞船贴着巨大的毛线行星高速绕行，拉链船身上纽扣在阳光下反光，夸张 FPV 运镜紧咬船尾，超精细毛绒材质。环境音：布料摩擦的沙沙声，BGM：轻快俏皮的拨弦。
[00:05 - 00:10] 中景：深蓝长绒毛的星际鲸兽从星云中冲出，玻璃纽扣般的眼睛逼近镜头，镜头快速后撤拉远。音效：低沉的鲸吼由远及近。
整体风格：超精细毛绒材质、电影级太空尺度、可爱外形与强烈动作反差，20 秒 21:9 超宽银幕画幅。
```

> 示例改编自官方 20 秒毛绒宇宙冒险样例。

## 高频违规

1. **分镜时长和 ≠ 总时长**：每镜 4–6s 是建议，和必须等于 duration 参数。
2. **音频描述放错位置**：台词/音效应写在该发生的镜头内，不要堆在开头总述。
3. **多主体无空间关系**：多主体同框要写清左右/前后/高低位置。
4. **睿频踩 30s 上限**：总时长硬顶 30 秒，超长需求拆多次生成。
5. **中英混杂缩写**：模型对多语言友好但对缩写敏感，术语全称。
