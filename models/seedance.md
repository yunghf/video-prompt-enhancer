# Seedance 1.0（火山方舟）适配规范

依据火山方舟《Seedance 1.0 系列提示词指南》整理。适用于文生视频（t2v）与图生视频（i2v）。

## 提示词公式

```
[主体] + [环境] + [视觉风格] + [镜头运动] + [光照] + [情绪]
```

- t2v：一句话说清"谁在哪做什么"，动作按时序展开。
- i2v：描述"相对首帧发生了什么"，动作从静止帧自然生长（如"男子转头，看向镜头微笑"）。
- **保持简洁，15–40 个词为宜**；长提示词会稀释模型注意力。多动作按时序串成一句（"拿起酒杯，喝了一口后放下，然后起身离开座位"）。
- **不支持缩写**（abbreviations are not supported）：全称写出，不写 "B-roll""POV shot" 等简写。
- 多主体场景用角色标识（"同事 A""吉他手"）分别描述各自动作，避免抢戏。
- 参考图以 `@图像N` 引用（多参考叙事最多 12–18 张，以产品当前版本为准）。

## 参数（API）

| 参数 | 合法值 | 说明 |
|---|---|---|
| resolution | 480p / 720p / 1080p | 文生/图生通用 |
| ratio | 16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 21:9 | i2v 可用 adaptive 保留输入比例 |
| duration | 5 / 10（s） | fast 版同；frames（29）二选一 |
| camera_fixed | true / false | 是否固定相机 |
| seed / watermark | 整数 / 布尔 | 复现与水印 |

旧速记语法（文本内追加）：`--rs 720p --rt 16:9 --dur 5 --cf false --wm true`；新式 API 用 JSON content 数组，`text` 字段放提示词正文。

## 示例

t2v：
```
女子走在夜晚的上海街头，霓虹灯牌在雨后路面上反射出蓝红双色光，镜头从侧面缓慢跟随，电影胶片质感，孤独而清醒的情绪
```

i2v：
```
稳重冷漠的男孩看向镜头，放下耳麦，然后跳下轮胎走向镜头蹲下
```

参数化（JSON）：
```json
{ "type": "text", "text": "小猫对着镜头打哈欠 --rs 720p --rt 16:9 --dur 5 --cf false --wm true" }
```

## 高频违规

1. **缩写**：任何未展开的英文缩写都可能不被识别。
2. **超长罗列**：超过 40 词的标签墙导致模型抓错重点。
3. **运镜打架**："环绕+推拉+横移"同时要求；只留一个主方向。
4. **参数越界**：duration 写 7/8、ratio 写 2.35:1（正确写法 21:9）。
5. **i2v 描述静止帧内容**：i2v 提示词写"画面里有什么"而非"发生什么"。
