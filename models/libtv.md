# LibTV 适配规范

LibTV 是"无限画布 + 节点工作流"形态的 AI 视频创作平台：底层聚合 Star Video 2.0 及可灵 3.0、Wan、Seedance、Seedream 等多模态模型，创作单元是节点（文本/图片/视频/音频/脚本），提示词在节点内编写并引用上游节点。本规范聚焦其原生视频节点（star-video2）的提示词写法。

## 工作流形态

- 节点入边（modeType）：`text2video`（纯文生）/ `singleImage2video`（单图微动作）/ `frames2video`（1–2 图锁首尾帧）/ `image2video`（1–9 图多参考）/ `mixed2video`（1–15 项图+视频+音频混合）。
- 上游引用语法：`{{Image 1}}`、`{{Image 2}}`、`{{Video 1}}` 指向连线顺序的第 N 个上游节点，**必须用在描述其作用的句子里**（如"`{{Image 1}}` 锚定脸型发型"）。
- 固定参数：`ratio=16:9`、`resolution=720p`（试错）/`1080p`（定稿）、`duration=4–15`（8 为生产默认）、`enableSound` 按需、`model=star-video2`。

## 七条铁律（社区踩坑沉淀）

1. **质感词锁死**：开工先定一句固定质感词（如 "2D 柔和动画绘本插画风格，gentle 2D storybook；绝不要 3D/写实"），所有图/视频节点原样复用，保证全片同风格。
2. **定版图作锚**：涉及已定版角色/场景/道具，必须挂定版图（角色图放第一张），绝不只靠文字还原。
3. **角色铁律**：以第一张图为准锁定脸型/发型；服装与角色图解耦（"设定图只取脸发型，衣服完全不按图"），正面描述新服装并排除原款特征；写明年龄与约 6.5 头身，禁幼态/大头娃娃/变形。
4. **零文字零数字**：画面内不写任何字（单据画横线、屏幕画亮屏），并注明"格号/箭头是标注不是画面内容"，否则视频会照抄穿帮。
5. **负面词反召唤**：模型对否定指令弱——要排除某元素就**通篇不提它的名字**，改用正面穷举"画面里有且只有：……"。
6. **场景锁定 + 控时长**：长镜头后半会漂移，写"全程同一房间、家具按图不变"；时长压到 ≤12s 降低漂移。
7. **镜头以人为主体**：挂场景图易变成环境展示片，写"镜头紧跟人物、禁长段空镜/环境运镜，场景只是背景"。

## 提示词骨架

```
{{Image 1}} 锚定脸型发型，确定角色为 25 岁左右东亚女性（成年约 6.5 头身）；
她穿米色针织衫坐在 {{Image 2}} 的教室课桌前，双手握笔低头写字，笔尖轻微晃动；
镜头从肩后缓慢推近至中景，暖色午后阳光从画面左侧进入；
画面里有且仅有：课桌、书本、台灯与窗外虚化树影；格号与标线是标注不是画面内容；
全程同一教室，镜头紧跟人物，禁环境空镜。质感：2D 柔和动画绘本插画风格。
```

## 高频违规

1. **负面词点名**："不要出现文字"会召唤文字；改为"画面里有且仅有：……"正面穷举。
2. **无锚点纯文字还原角色**：角色必挂定版图且放第一张。
3. **服装渗透**：角色图自带服装时模型连衣服一起抄——脸衣解耦写法。
4. **长镜头漂移**：>12s 且无场景锁定声明时后半段漂移。
5. **环境空镜**：挂场景图后镜头变成展示片——写明"场景只是背景"。
6. **引用裸奔**：`{{Image 1}}` 出现在句首而无作用说明。
