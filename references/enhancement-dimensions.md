# 八维度展开方法论

把用户的一句话创意（"橘猫在屋顶看日落"）增强为八维度素材表，再按目标模型裁剪。**先展开、后裁剪**——缺维度是常见失败源，多维度则由模型边界裁掉。

## 八维度总表

| 维度 | 要回答的问题 | 提法示例 | 质量标准 |
|---|---|---|---|
| 画面主体 | 谁/什么在画面里，外观如何 | "一只橘色短毛猫，琥珀色眼睛，脖颈系褪色红围巾" | 可视觉定位；同一主体全篇一个称呼 |
| 动作细节 | 主体在做什么，先后顺序 | "蹲坐→竖耳→抬爪扑蝶" | 每镜一个主动作；多动作按时序给出 |
| 场景氛围 | 环境、时间、天气、情绪基调 | "黄昏老城瓦房顶，远处炊烟，盛夏余热" | 有时间、地点、情绪三要素 |
| 运镜方式 | 镜头如何动、景别与机位 | "缓慢推近至中景，低机位微仰" | 一个主要方向；幅度速度明确 |
| 光影质感 | 光源、时段、色调、材质 | "侧逆光勾金边，暖橙主调，瓦片粗糙质感" | 光源方向+时段+色调 |
| 艺术风格 | 流派/质感参照 | "电影感、胶片颗粒、宫崎骏动画风" | 用公认参照，不自造名词 |
| 画面比例 | 输出画幅 | 16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 21:9 | 只取目标模型合法值 |
| 视频时长 | 片段长度 | 5s / 8s / 10s / 15s / 30s | 只取目标模型合法值 |

## 展开规则

1. **主体优先具体化**：脸型/发型/服装/年龄/体态逐项给，不自造标签。"好看的女孩"是废维度；"二十多岁女性，鹅蛋脸，浅棕眼睛，长波浪黑发，米色风衣"是可复用维度。
2. **动作有时序**：复杂动作拆成带先后的小节（"先拿起酒杯，喝一口后放下，再起身离开"），每个动作留足时间。
3. **运镜一个主方向**：同时要求环绕+推拉+摇移会互相抵消。小幅调整用 "with small amplitude" 或"略微"限定。
4. **光影三件套**：光源方向（侧光/逆光/顶光）+ 时段（黄金时刻/正午/蓝调时刻）+ 色调（暖橙/冷蓝/低饱和）。
5. **风格用参照物**：电影感、纪录片、水墨、赛博朋克、吉卜力动画——都是模型认识的语言。
6. **氛围带动情绪词**：宁静、紧张、浪漫、荒诞——用一个主情绪，不混三个以上。
7. **音频按需加入**：模型支持原生音频时（Wan 3.0、可灵、H3、Seedance 部分版本），把环境音/台词/BGM 作为独立子维度写进提示词；不支持的模型不带音频词。
8. **先展开后裁剪**：如目标模型无比例参数（H3），裁剪掉比例维度；如 Seedance 短提示词场景，把维度压成公式（[主体]+[环境]+[风格]+[运镜]+[光照]+[情绪]）而非罗列八段。

## 维度组合侧重

- **短视频信息流（3–15s）**：重主体 + 动作 + 运镜；氛围一句话带过。
- **产品展示**：材质 + 光影 + 运镜（环绕/推近细节）；动作只保留产品本身的揭示动作。
- **角色/叙事多镜头**：主体定义 + 时序动作 + 台词；每镜景别写清（中景/特写/全景）。
- **产品/APP 图标化短镜头**：比例优先（9:16 / 1:1），时长压短，动作收敛为单一微动作。

## 反面模式（出现即返工）

| 反面模式 | 症状 | 修正 |
|---|---|---|
| 标签堆叠 | "唯美，治愈，电影感，高级感，氛围感"全上 | 只留一个主情绪 + 一个风格参照 |
| 主体漂移 | 同一主体三个称呼 | 全篇锁定一个称呼 |
| 动作过载 | 单镜头内跳舞+变装+起飞+爆炸 | 一镜一动作，其余分镜 |
| 参数臆造 | 写 "duration=7s"（模型只支持 5/10s） | 查模型参数表后取合法值 |
| 音频幻觉 | 不支持音频的模型写 "台词：……" | 裁剪音频维度 |
