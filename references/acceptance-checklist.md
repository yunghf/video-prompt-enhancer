# 验收清单与迭代协议（全模型）

每轮改动后逐项检查，不看"画面好不好看"，只看可检查维度。机器可判定项先跑 `scripts/validate_video_prompt.py --model <模型>`，本清单补齐语义项。

## 五类验收清单

### 1. 形状检查（按模型）
- H3 Base：恰好三字段且顺序正确？Ref2VA：六段非空且顺序正确？
- 可灵：`镜头 n, m, words;` 语法、半角分隔、每镜 ≤512 字符、分镜数 1–6？
- Wan 3.0：多镜头带 `[MM:SS - MM:SS]` 时间戳、每镜 4–6s、分镜和 = 总时长？
- LibTV：`{{Image N}}` 引用带作用说明、无点名负面词？
- Seedance：15–40 词简洁度、无缩写、t2v/i2v 描述对象正确？

### 2. 参数检查
- duration 是否在目标模型合法集内（H3 4–15s 整数、Seedance 5/10、Wan 3.0 2–30 或 -1、可灵 3–15、LibTV 4–15）？
- ratio 是否在合法集内（如 Seedance 21:9 / 4:3 / 3:4 独占、LibTV 以 16:9 为主）？
- resolution 取模型合法值（480p/720p/1080p）？

### 3. 时间轴检查（H3 / 可灵 / Wan 3.0）
- H3：`[Shot 1]` 无时间戳、后续切点严格递增且在时长内、尾帧 `S.SS` 两位小数且等于实际秒数、对齐行在首字段前？
- 可灵：各分镜 `m` ≥1 且和 = 总时长？
- Wan 3.0：时间戳切点严格递增、末镜结束点等于总时长？

### 4. 边界检查
- 对白/画内声音是否进入 H3 `overall_soundscape` 或 `non_diegetic_music`？
- 引用标签（H3 `<Subject N>` 等、可灵 `@`、LibTV `{{Image N}}`）是否先定义后使用、无拼写断裂？
- 音频维度是否只出现在支持原生音频的模型上？

### 5. 约束保持检查
- 上一轮锁定的主体外观/场景/动作约束是否被无声修改？
- 八维度中本轮未涉及的维度是否保持原样？

## 每轮变更记录模板

```
## 第 N 轮变更（目标模型：<模型名>）
- 改动维度/字段：<如：运镜方式 / non_diegetic_music>
- 改动原因：<引出的问题 / 验收失败项编号>
- 预期影响的验收项：<清单项 1-5>
- 保持未动的锁定约束：<主体外观/场景/时长/比例等锁定项>
- 回滚方式：<恢复到第 N-1 轮提示词>
```

多轮之间比较"维度变化"而不是比较整段文案，迭代才不会退化成重写。

## 最小测试集：从真实失败中生长

每发生一次失败，沉淀一个最小用例：

```
用例 ID：F-001
模型：<模型名>
失败现象：<如：可灵分镜时长和 12s ≠ 总时长 10s>
检查项：<对应清单项编号>
最小可复现提示词：<只保留触发该失败的片段>
回归状态：<未修复 / 已修复 / 已监控>
```

常见起点：缩写混进 Seedance、可灵分镜和不等、Wan 3.0 末镜超时、LibTV 负面词点名、H3 对白混入 soundscape、主体称呼漂移。测试集必须可观测，不引入主观评分。

## 素材权威矩阵（写参考定义前，H3/LibTV 场景）

对每个参考素材先定唯一主角色，跨轮稳定复用：

| 素材 | 唯一主角色 | 冻结属性 | 出现镜头 |
|---|---|---|---|
| <素材 ID> | 身份 / 场景 / 动作 / 声音（四选一） | <外观、构图、姿态、声线等锁定项> | [Shot ...] |

一个素材承担多个重叠角色 = 输入间未定义竞争，是最常见的结构性失败源。
